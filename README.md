# opo-lopo — Oposiciones Auxiliar Administrativo (C2) · Ayuntamiento de Guadarrama

Plataforma de estudio para la oposición libre a 17 plazas de Auxiliar Administrativo/a
(subgrupo C2, Administración General) del Ayuntamiento de Guadarrama, OEP 2026.

Contenido:

- `fuentes/` — bases oficiales, textos legales consolidados del BOE (única fuente de verdad) y exámenes de otras convocatorias.
- `temario/` — apuntes de los 38 temas, generados exclusivamente a partir de `fuentes/leyes/`.
- `banco-preguntas/` — preguntas tipo test verificadas (Generador → Verificador → Árbitro).
- `verificacion/` — registros del proceso de verificación.
- `plataforma/` — app web estática (PWA) para estudiar, practicar y hacer simulacros.
- `scripts/` — agentes de generación/verificación y monitor de cambios en el BOE.
- `docs/` — plan de trabajo (prompts por fases).
- `progreso.json` — estado de cada fase y tema.

Ver `CLAUDE.md` para las reglas de trabajo.
